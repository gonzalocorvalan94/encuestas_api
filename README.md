# Sistema de Encuestas

## Descripción

Sistema web destinado a la creación, publicación y respuesta de encuestas.

El sistema permite registrar respuestas y consultar los resultados obtenidos
mediante preguntas con opciones de respuesta predefinidas, sin permitir
respuestas de texto libre.

Los diagramas del proyecto se encuentran organizados dentro de la carpeta
`docs/diagramas/`.

Cada tipo de diagrama cuenta con su propia subcarpeta:

- `docs/diagramas/dfd/` - Diagramas de Flujo de Datos
- `docs/diagramas/entidad-relacion/` - Diagrama Entidad-Relación

# Metodología

El proyecto se organiza mediante una metodología Kanban para visualizar
las tareas pendientes, en proceso, en revisión y terminadas.

Además, el desarrollo se plantea mediante cuatro sprints de dos semanas:

- **Sprint 1:** Creación de encuestas
- **Sprint 2:** Participación en encuestas
- **Sprint 3:** Generación de reportes
- **Sprint 4:** Mejoras, seguridad y pruebas finales
