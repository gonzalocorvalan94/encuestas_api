# Análisis de Factibilidad

## Factibilidad Operacional
* **Evaluación:** Alta
* **Detall:** El concepto de encuestas con opciones es familiar para la mayoría de las personas. Tanto los creadores como los participantes entenderán rápidamente cómo usar el sistema.

## Factibilidad Económica
* **Evaluación:** Alta
* **Detalle:** El desarrollo es sencillo y los costos de infraestructura son bajos (un servidor web y una base de datos). Los beneficios incluyen mejor toma de decisiones, mayor satisfacción del cliente y detección temprana de problemas.

## Factibilidad Técnica
* **Evaluación:** Alta
* **Detalle:** Se puede implementar con tecnologías web estándar y bases de datos relacionales, con las cuales el equipo de desarrollo está familiarizado.

## Factibilidad de Cronograma
* **Evaluación:** Alta
* **Detalle:** El alcance está claramente definido y no requiere investigaciones complejas ni tecnologías experimentales.e
