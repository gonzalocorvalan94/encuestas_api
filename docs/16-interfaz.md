# Diseño de Interfaz de Usuario

## Pantalla de creación de encuesta
El administrador ve n formulario donde puede ingresar el título y la descripción de la encuesta. Luego, un área donde puede agregar preguntas dinámicamente. Para cada pregunta, debe escribir el texto y agregar las opciones de respuesta.

## Pantalla de respuesta para el participante
El participante ve las preguntas de la encuesta de forma secuencial. Las opciones se presentan como botones de selección. Un botón de "Enviar respuestas" finaliza la participación, y el sistema muestra un mensaje de confirmación.u
